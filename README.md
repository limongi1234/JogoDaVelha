# Jogo da Velha (Eletrônico) ⭕❌

Implementação do clássico **Jogo da Velha** em **C++**, rodando no terminal. Projeto acadêmico da disciplina de **Estrutura de Dados e Algoritmos** (UNIFESO, Ciência da Computação).

## ✨ Características

- Tabuleiro 3x3 representado por **matriz**
- Jogo para dois jogadores, alternando as jogadas
- Verificação de vitória, empate e validação das posições
- Interface em texto no terminal

## 🛠️ Tecnologias

![C++](https://img.shields.io/badge/C%2B%2B-00599C?style=flat&logo=cplusplus&logoColor=white)

- **C++** — lógica do jogo e manipulação de matriz

## 🚀 Como executar

```bash
git clone https://github.com/limongi1234/JogoDaVelha.git
cd JogoDaVelha

g++ jogodavelha.cpp -o jogodavelha
./jogodavelha
```
